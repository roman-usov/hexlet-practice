## sameParityFilter.js

Implements and exports a function that takes in an array of integers and returns a new array containing integers whose parity is the same as that of the first element in the original array.


```js
sameParity([-1, 0, 1, -3, 10, -2]); // [-1, 1, -3]
sameParity([2, 0, 1, -3, 10, -2]); // [2, 0, 10, -2]
sameParity([]); // []
```
